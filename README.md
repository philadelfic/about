# Портал Олега Орловского

Личный портал: коротко о себе, живая информация о проектах, статьи и материалы для студентов.
Живёт на GitHub Pages: https://philadelfic.github.io/about/

## Стек

- [Astro](https://astro.build) — статический сайт, контент в markdown
- GitHub Actions — сборка и деплой на GitHub Pages

## Локальная разработка

```bash
npm install
npm run dev       # http://localhost:4321/about/
npm run build     # сборка в dist/
npm run preview   # предпросмотр собранного сайта
```

## Предпросмотр

```bash
npm run preview          # предпросмотр сборки на http://localhost:4321/about/
./scripts/preview.sh     # сборка + предпросмотр без host-проверок (работает и через туннель)
./scripts/tunnel-bore.sh # временный публичный адрес (без страницы-предупреждения)
./scripts/serve-appsrv.sh # опубликовать на appsrv: http://192.168.3.111:3040/about/
```

## Ветки и деплой

| Ветка | Что происходит |
|---|---|
| `dev` | разработка; CI собирает проект, деплоя нет |
| `test` | мерж из `dev`, полная проверка (сборка, ссылки, Lighthouse) |
| `main` | прод: сборка и деплой на GitHub Pages по push |

Push в `main` = выложено.

## Структура

```
src/
  pages/        # страницы сайта (главная, обо мне, разделы)
  layouts/      # общий каркас страницы
  styles/       # общие стили
  data/site.ts  # контакты и внешние ссылки
```

Ветка `dev` — рабочая. Всё, что не описано здесь, — в спеке: Outline «My projects» → «Портал — концепция и дизайн».

## Материалы курса

* Контент — в `src/content/`: `topics/` (тема: тело файла = теория, `covered[]`, `qa[]`), `homework/`, `seminars/`.
* Схемы и картинки — в `public/img/course/<курс>/`. В markdown путь пишем от корня сайта:
  `![подпись](/img/course/rl/step-chain.png)` — базовый префикс (`/about`) добавляет rehype-плагин в `astro.config.mjs`.
* Формулы и схемы вставляем картинками из презентаций (готовые PNG), а не текстом.

* Даты в контенте пишем полностью, с годом: `date: '18.09.2026'`, `due: '25.09.2026'`.
* В конце темы — список терминологии (в `terms` у темы): термин и одно предложение объяснения.
