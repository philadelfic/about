## Что дописать

В `agent.py` два места, оба помечены `raise NotImplementedError`. Запускаете — программа не падает,
а печатает `[нет]` и говорит, чего не хватает.

Первое — `update()`, правило обновления оценки. Шаг строкой выше уже посчитан: `1/n` по этому рычагу
или `α`, если он задан. Остаётся сдвинуть оценку:

```python
self.q[act] += step * (reward - self.q[act])
```

Первое наблюдение по рычагу оценку не подтягивает, а задаёт — эта строка в коде уже написана, её
трогать не надо.

Второе — `act()`, ε-жадный выбор. С вероятностью `epsilon` берём любую руку, иначе лучшую по текущим
оценкам:

```python
if self.rng.random() < self.epsilon:
    return self.rng.choice(APPROACHES)
return self.greedy_choice()
```

## Как понять, что получилось

`python3 agent.py` строит ряд `1 → 0,5 → 1,0` при `1/n` и другой ряд при `α`; в конце все строки `[ok]`.

`python3 run.py` печатает таблицу стратегий — она должна сойтись с той, что была на занятии. Если
разошлась, смотрите на строки с `[нет]`: там сказано, какое место ещё не вписано или какое число
не сошлось.

Дальше два прогона, они же материал для отчёта: `python3 run.py --png` кладёт `bandit-1000.png` рядом
с `run.py`, `python3 run.py --exp` рисует три панели — доход, оценки Q, доли выбора. Если matplotlib
не встал, `--exp` печатает ту же картину таблицей по сотням спринтов, для выводов этого хватает.

Совсем не помните, откуда формула, — в шапке `agent.py` две ссылки: «Как двигается оценка» на странице
семинара 3 и «ε-жадная стратегия» в теме 2.

## 4. Три вывода

3. …

Правило курса: число плюс объяснение, почему так. Вывод без числа не считается, число без объяснения
тоже. Три штуки — потому что первые два обычно очевидные, а третий и есть ваш.

Если не знаете, с чего начать, вот что на этом занятии вылезало у всех:

- как ведёт себя ε: 0,01 — разведки не хватает, 0,5 — платите слишком много, 0,1 между ними;
- почему жадная при `q0 = 0` застревает на первом по алфавиту рычаге при любом seed;
- зачем оптимистичной и UCB случайные шаги, если они и так обходятся без них;
- что делают с оценками Q шаги 0,9 и 0,01 — и где тут нестационарность.
