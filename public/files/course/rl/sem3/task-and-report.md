## Задание — что дописать в коде

В `agent.py` не хватает ровно двух мест. Оба помечены заглушкой `raise NotImplementedError`
с подсказкой — программа не падает, а печатает `[нет]`.

### 1. `update()` — правило обновления оценки

Оценка сдвигается на шаг, умноженный на разницу между наградой и оценкой:

```python
self.q[act] += step * (reward - self.q[act])
```

`step` уже посчитан строкой выше: это `1/n` по этому рычагу (честное среднее по всей истории)
или постоянный `α`, если он задан. Первое наблюдение по рычагу оценку задаёт, а не подтягивает —
эта строка в коде уже есть.

Проверка: `python3 agent.py` строит ряд `1 → 0,5 → 1,0` при `1/n` и другой ряд при `α`.

### 2. `act()` — ε-жадный выбор

С вероятностью `epsilon` — любая рука наугад (разведка), иначе — рука с лучшей оценкой:

```python
if self.rng.random() < self.epsilon:
    return self.rng.choice(APPROACHES)
return self.greedy_choice()
```

Проверка: `python3 run.py` — таблица стратегий должна сойтись с занятием.

Требование к каждому: **число + объяснение «почему так»**. Вывод без числа не считается;
число без объяснения — тоже.

Подсказки, о чём обычно получаются выводы:

* что делает ε: сравните 0,01 / 0,1 / 0,5 — где стратегия «не успевает», где «слишком много платит»;
* почему жадная при `q0 = 0` застревает на первом по алфавиту рычаге при любом seed;
* почему оптимистичная и UCB обходятся без случайных шагов;
* что происходит с оценками Q при `α` = 0,9 и 0,01 — и при чём тут нестационарность.
