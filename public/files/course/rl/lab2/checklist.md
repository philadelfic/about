# Чек-лист критериев лабораторной 2

Заполняется вами и сдаётся вместе с отчётом. В колонке «где» — конкретный раздел или таблица
**вашего** отчёта. Ссылка на несуществующий раздел = чек-лист не заполнен, работа к приёмке не принимается.

| № | Критерий | Где в отчёте (раздел, таблица) | Готово |
|---|---|---|---|
| 1 | Постановка формализована: сцена, рычаги, вознаграждение, что дрейфует и с каким σ | | |
| 2 | Все три обязательных исследования, ≥ 100 сидов на точку, медиана + IQR | | |
| 3 | Каждый вывод подкреплён цифрой из собственных прогонов (минимум три вывода) | | |
| 4 | Код воспроизводится командой из отчёта | | |
| 5 | Обоснование любых заимствованных кусков кода (ОТВЕТ.md + ссылка в отчёте) | | |
| 6 | `run_log.jsonl` содержит все обязательные поля, числа в отчёте совпадают с логом | | |

**Обязательные поля `run_log.jsonl`:** `n_runs`, `seed_from`, `seed_to`, `metric`, `command`.

**Что сдаётся:** REPORT.md + код + два графика + этот чек-лист + `run_log.jsonl` — в чат до начала шестой практики (гр. 1 — 10.11, гр. 2 — 13.11). Устной защиты нет, пересдача одна — до восьмой практики (24.11 / 27.11).
