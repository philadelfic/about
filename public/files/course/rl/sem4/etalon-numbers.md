Что читать в таблице:

## Regret: та же картина, другая шкала

Метрика «доля текущего лучшего» бинарна: промах на тысячную и промах на полбалла считаются одинаково. Regret различает цену промаха:

regret = среднее по шагам ( max_a μ_t(a) − μ_t(A_t) ), где μ_t — средние, из которых снята награда, A_t — выбор агента.

Считается офлайн по тому же `mu_log`, агенту μ видеть не нужно. Отдельный замер: `python3 tools/regret.py --seeds 240` (код агента и среды не менялся).

| Стратегия | Regret за спринт: медиана [IQR] |
| --- | --- |
| жадная | 0,62 [0,41–0,87] |
| ε-жадная 0,1 · 1/n | 0,24 [0,15–0,34] |
| ε-жадная 0,1 · α 0,1 | 0,13 [0,10–0,16] |
| ε-жадная 0,1 · α 0,3 | 0,10 [0,08–0,12] |
| UCB c = 2 · 1/n | 0,09 [0,06–0,12] |
| UCB c = 2 · α 0,1 | 0,08 [0,06–0,11] |
| градиентная h = 0,1 | 0,22 [0,14–0,32] |
| оракул | 0,00 |

Что читать:
- **порядок в целом тот же** (1/n хуже α, жадная хуже всех, градиентная в середине), но верхняя часть таблицы читается иначе: по доле лучшего UCB и ε с α = 0,3 почти равны (74% против 76%), а по regret UCB впереди вдвое с лишним по отрыву от жадной — промахивается он чаще, но дешевле, потому что берёт вторую руку, а не худшую.
- **разбросы перекрываются**: 0,06–0,12 у UCB против 0,08–0,12 у ε с α = 0,3. Это направление, а не доказательство — честный пункт «исследования 4+».
- **regret оракула ровно 0** — по построению (он выбирает по тому же логу). Это проверка кода, а не результат замера.
