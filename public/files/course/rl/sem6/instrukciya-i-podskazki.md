# Инструкция и подсказки — кафе-симулятор (obed)

Код семинара 6 по обучению с подкреплением. Бандит «где обедать»: четыре группы блюд по три в каждой, пять характеров-стратегий, мир умеет дрейфовать.

## 1. Как запустить

```
unzip obed.zip
cd obed
python3 obed.py --selftest
```

Ждём ответ `selftest: ok — все 5 стратегий × 2 шага обновления, 20 дней, без ошибок`. Если так — всё на месте. Дальше `python3 obed.py --help`.

Нужен только Python 3 (3.6 и новее), сторонних библиотек нет. Все файлы лежат в одной папке, ставить ничего не надо.

**Windows:** там команда python3 — заглушка Microsoft Store, она открывает магазин. Запускайте py obed.py --selftest или python obed.py --selftest (Python 3.8+). Если папка на сетевом диске или в пути есть пробелы — берите путь в кавычки.

## 2. Что в файлах

| Файл | Что внутри |
|---|---|
| `obed.py` | запуск: флаги, режимы, разбор команд |
| `game.py` | движок: день за днём, дуэль двух команд, печать таблицы |
| `world.py` | мир кафе: коридоры средних, дрейф по σ |
| `menu.py` | блюда и группы (4 группы × 3) |
| `knobs.py` | ручки: `EPSILON`, `ALPHA`, `C_UCB`, `ETA`, `Q0` |
| `agents.py` | реестр характеров и синонимов |
| `base.py` | общий класс стратегии |
| `greedy.py`, `epsilon.py`, `ucb.py`, `gradient.py`, `optimistic.py` | по одному характеру в файле |

## 3. Два режима

Дуэль двух команд:

```
python3 obed.py --duel завсегдатай,завсегдатай,завсегдатай,завсегдатай любопытный,любопытный,любопытный,любопытный
```

В команде ровно четыре характера — по одному на группу: первое, второе, десерт, напиток. После двоеточия можно выбрать шаг обновления: `пятница:avg` — честное среднее 1/n, `пятница:alpha` — постоянный шаг.

Игра против машины:

```
python3 obed.py --play --vs тянущийся --days 30
```

Каждый день выбираете блюдо цифрой 1–3. Нужен живой терминал.

Флаги: `--days` (по умолчанию 200), `--seed` (7), `--sigma` (0.05 0.05 0.01 0.2 — по группам), `--log N` (печать прогресса каждые N дней), `--epsilon 0.1 --alpha 0.1 --c 2.0 --eta 0.1 --q0 5.0` (ручки стратегий).

## 4. Что делаем на паре

1. Распаковали, прогнали `--selftest`.
2. Сверка — один мир, одно число: дуэль `завсегдатай` против `любопытный` на 100 дней с сидом 7. Должно выйти доход 345.07 против 409.01. Если у вас другие числа — вы где-то поменяли мир или сид.
3. Ручка — одна правка, другой итог: `пятница:avg` против `пятница:alpha` на тех же 100 днях и сиде 7. Выходит 372.65 против 376.09. Затем то же с `--sigma 0 0 0 0` — и результат переворачивается: 456.44 против 455.44.
4. Все против завсегдатая: в первой команде четыре `завсегдатай`, во второй — свой характер.
5. Таблица на доске: каждая команда пишет строку «характер · доход · доля лучшего · что менял».
6. Человек против машины: `--play --vs тянущийся --days 30`, потом обсуждаем, где человек проиграл и почему.

## 5. Подсказки и грабли

- **Windows:** python3 — заглушка магазина; используйте py или python.
- Характеры: `завсегдатай` (жадный, он же `сидит`), `пятница` (`eps`), `любопытный` (`ucb`), `тянущийся` (`gradient`), `оптимист` (`optimistic`).
- Кириллические команды берите в кавычки: `--duel 'завсегдатай,...' 'пятница,...'`, иначе шелл может порезать запятые.
- Десятичная запятая работает: `--sigma 0,05` то же, что `0.05`.
- Ставка перед дуэлью необязательна: Enter — без ставки. При перенаправлении ввода ставку вообще не спрашивает.
- `--play` без терминала выходит с подсказкой — это не падение.
- На Windows символ σ в выводе может стать «?» — тоже не ошибка, так и задумано.
- Один и тот же `--seed` даёт один и тот же результат: на этом строится сверка. Меняете сид — меняются числа, и это уже другой эксперимент.
