## 1. Цель работы

Научиться оценивать ценности состояний табличным методом TD по опыту, без модели среды: self-play в крестиках-ноликах, обновление таблицы ценностей, настройка шага обучения α и исследование ε. Показать на числах, как α и ε влияют на качество выученной стратегии.

## 2. Постановка задачи

Игра крестики-нолики 3 × 3. Агент обучается, играя сам с собой (self-play).

Обязательное формальное описание — без него работа не принимается:

- **состояние** — позиция на доске (размещение крестиков и ноликов);
- **действие** — номер свободной клетки;
- **вознаграждение** — +1 за выигрыш, 0 за ничью, −1 за проигрыш; начисляется в конце партии, промежуточные шаги — 0;
- **γ = 1, с обоснованием** — партия конечна, сумма конечна (эпизодическая задача);
- **обучение** — TD-обновление таблицы ценностей позиций после каждого хода; выбор хода — ε-жадный.

Два правила, без которых таблицы у разных работ несравнимы:

- **Нормализация позиций.** Восемь симметрий доски (повороты и отражения) схлопываются в каноническую форму — минимальное строковое представление среди всех восьми. Таблица хранится только для канонических форм. В отчёте заявляется **размер таблицы после схлопывания** — это контрольный пункт сверки.
- **Чей ход.** Позиция всегда записывается от лица игрока, который должен ходить: при self-play это выполняется само, при оценке против оппонента интерпретация таблицы переворачивается для второго игрока.

## 3. Среда

Среда — дельта от каркаса занятия 7 (файлы выдаются на занятии и уходят в чат после него):

- доска 3 × 3; словарь позиций (достижимых позиций 5478, после канонизации — 765);
- проверка конца партии: восемь выигрышных линий, ничья при заполненной доске;
- фиксированные оппоненты для оценки: **случайный** и **жадный эвристический** — правило эвристики задано в каркасе явно (выиграть, если есть ход-выигрыш; иначе заблокировать ход-выигрыш противника; иначе центр или угол);
- контрольный скрипт `count_positions.py` печатает два числа — 5478 и 765; если у вас не 765, сломана канонизация, а не теория.

## 4. Методы (минимум для сравнения)

- TD-обучение ценностей состояний по self-play;
- базовая точка: **α = 0,1, ε = 0,1**;
- исследование по α: **0,05 и 0,5** при ε = 0,1;
- исследование по ε: **0,01 и 0,3** при α = 0,1;
- свои значения — по желанию, за плюс.

## 5. Обязательные исследования

1. **Влияние α.** При фиксированном ε сравнить два обязательных значения α с базовым; результат — кривая обучения (доля побед против случайного оппонента по мере эпизодов) и пояснения.
2. **Влияние ε.** При фиксированном α сравнить два обязательных значения ε с базовым; результат — кривая обучения и пояснения.
3. **Качество выученной стратегии.** Обученный агент против **обоих** фиксированных оппонентов **в обеих ролях** (первый и второй ход) — на каждого оппонента две колонки, доля побед числом.
4. **Гипотеза для проверки:** слишком большая α даёт дрожащие оценки и нестабильную игру; слишком маленькая ε — раннюю фиксацию на слабой стратегии. Подтвердить или опровергнуть своими числами.

**Исследование 4+ (бонус, за плюс).** Обучаемая стратегия вместо ε-жадной: softmax по позициям (как предпочтения градиентного бандита), таблица ценностей работает критиком, обновление — по TD-ошибке. Простейший «исполнитель-критик». Сравнить с базовой точкой по доле побед против обоих оппонентов в обеих ролях и по устойчивости кривой. Скелет с пропусками — отдельным файлом `bonus_actor_critic.py`. На оценку обязательной части не влияет.

## 6. Требования к числам

- **Не менее 100 независимых прогонов на каждую точку** таблицы. Прогон — обучение с нуля со своим seed.
- **Число эпизодов обучения в прогоне** одинаковое для всех точек и заявлено в отчёте. Ориентир базовой точки — 10⁴ эпизодов (точное число фиксируется преподавателем после замера и объявляется в чате).
- **Оценочных игр — 400 на прогон:** по 100 на каждого из двух оппонентов в каждой из двух ролей. Оценочные игры дёшевы относительно обучения, экономить на них нельзя.
- В отчёт: **медиана и IQR** доли побед, плюс среднее и разброс; для каждой точки — диапазон сидов и команда запуска.
- Лог `run_log.jsonl` по спецификации курса: одна строка на точку, обязательные поля `n_runs`, `seed_from`, `seed_to`, `metric`, `command`; для бонуса — строка с `point_id = "bonus"`.

**Медленная машина:** режется число эпизодов обучения (с обоснованием в отчёте), затем число эпизодов оценки, но не ниже минимума. **Число прогонов (100) не режется** — иначе ломается сравнимость с группой.
