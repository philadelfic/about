**The gist: memory can be shelved, not kept on one shelf.**

## 🌳 Areas as a tree

An area is a path of segments rather than a single word: “work / clients / projects” instead of a flat list. Every branch keeps its own notes, and a search inside a branch stays inside it.

## 📚 What came before

The first working version is release 1.0: notes, hybrid search, MCP tools, local embeddings. Hierarchy arrived here; three levels of depth came later (2.2.0).
