**Главное: у ассистента появилась память, которая живёт отдельно от чата.**

## 🧠 Что уже умеет

- заметки: сохранить, найти, прочитать, поправить, удалить — через MCP;
- поиск по смыслу (векторный) и по словам (полнотекстовый);
- эмбеддинги считаются локально через Ollama, без облака;
- хранилище — одна база SQLite рядом с сервисом, без внешней инфраструктуры;
- один контейнер: скачал, поднял, подключил к ассистенту.

## 🎯 Порог поиска откалиброван

Порог отсечения поднят с 0,35 до 0,50 — по эксперименту на 82 реальных запросах: в выдачу перестало попадать то, что никто не открыл бы.

## 📌 Что дальше

Разделы памяти пока плоские. Дерево разделов появится в 2.0.
