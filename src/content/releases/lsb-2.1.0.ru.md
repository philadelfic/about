**Главное: модели выбираются отдельно для каждого слота.**

## 🧩 Провайдер на каждый слот

У трёх внешних вызовов — эмбеддинги, суммаризация, судья — свои провайдер и модель. Рядом спокойно живут локальная Ollama и облачный API: не нужно подгонять всё под одного поставщика.

## 🔌 Единый клиент

Один транспорт для всех внешних вызовов вместо самодельных обёрток — ошибки, таймауты и повторы обрабатываются в одном месте.

## 🚦 Проверка на старте

Лёгкий запрос к каждому провайдеру при запуске: недоступная модель видна сразу, а не на первой задаче в очереди.

## ✍️ Редактируемые промпты

Три системных промпта вынесены в файлы — их можно править, не трогая код.

## 🏷 Заголовки заметок

У заметки появился заголовок; для новых он обязателен. По нему потом пришёл поиск по названию (2.2.0).

## ⚙️ Фоновые циклы по слотам

Три независимых цикла вместо одного: медленный слот больше не тормозит остальные.

## ♻️ Переиндексация при смене модели

Сменилась модель эмбеддингов — индекс пересчитывается сам, а не молча смешивает векторы от разных моделей.

## 💥 Ломающие изменения

Переменная `OLLAMA_BASE_URL` переименована в `EMBEDDING_BASE_URL`, а `keep_alive` убран из запросов.
