**Условие.** На семинаре 3 мы разобрали бандита и собрали работающий пример, но в коде занятия
осталось ровно два места, без которых он не запускается. Их и надо вписать — и показать числа,
которые получились.

**Что дописать** — два места в `agent.py`:

1. **`update()` — правило обновления оценки.** Оценка сдвигается на шаг, умноженный на разницу между
   наградой и оценкой: `self.q[act] += шаг · (reward − self.q[act])`. Шаг — честное среднее `1/n`
   по этому рычагу. Пока правило не вписано, в файле стоит заглушка с сообщением — программа не падает,
   а печатает `[нет]` с подсказкой.
2. **`act()` — выбор действия.** ε-жадный выбор: с вероятностью ε — любая рука наугад, иначе — рука
   с максимальной оценкой.

**Что сделать.**

1. Вписать два места, скачать три файла в одну папку и запустить `python3 run.py`. Готово, когда
   **все строки `[ok]`**: проверки в конце файлов смотрят на ваши числа и говорят, сходятся ли они
   с эталоном занятия.
2. Нарисовать картинку: `python3 run.py --png` — рядом появится `picture.png` с кривыми.
3. Прогнать пять стратегий — по одной команде на строку таблицы:

| Стратегия | Команда |
| --- | --- |
| жадная | `python3 run.py --exp --strategy greedy` |
| ε-жадная, ε = 0,1 | `python3 run.py --exp --strategy eps` |
| оптимистичная, Q₀ = 5 | `python3 run.py --exp --strategy optimistic` |
| UCB, c = 2 | `python3 run.py --exp --strategy ucb` |
| градиентная | `python3 run.py --exp --strategy gradient` |

4. Заполнить `task-and-report.md`: свои числа по пяти стратегиям (доход и доля выборов руки C), таблицу
   «что вписал — значение — почему такое», и **три вывода, каждый с числом** из ваших прогонов.
   Например: «жадная ни разу не выбрала C — 0 %, потому что не пробует».
5. Прислать в чат: `task-and-report.md` и `agent.py` (или три файла целиком).

**Что проверяем.**

* все строки `[ok]` при `python3 run.py` — код собран верно;
* числа в отчёте совпадают с вашими прогонами и попадают в диапазон эталона;
* три вывода — с числами и объяснением, а не пересказом таблицы;
* обоснование: почему выбрали такой шаг и такой способ выбора.

**Срок.** Приносите на пятую практику: группа М80-203СВ-25 — 03.11.2026, группа М80-202СВ-25 —
06.11.2026. Кто не успел — присылайте в чат, разберём на разборе.
