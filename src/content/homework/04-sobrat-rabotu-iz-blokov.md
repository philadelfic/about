**Условие.** На семинаре 2 работу собирали из трёх файлов: `environment.py` — среда, `agent.py` — агент,
`run.py` — прогон. Теперь то же самое собираем сами. На портале выложены те же три файла, но с пропусками:
механика и проверки внутри готовы, а чисел игры и двух мест «на подумать» нет. Файлы нарочно оставлены
чистым кодом, без подсказок: что вписать — здесь, в условии.

**Что уже готово.** Номера клеток и переходы, модель мира, выбор хода (жадно и ε-жадно), проход эпизода,
набор таблицы опыта прогонами и проверки в конце каждого файла. Действия — числа: 0 вверх, 1 вниз,
2 влево, 3 вправо; при равенстве оценок агент идёт вправо, как договаривались в лекции 4.

**Среда — `environment.py`, блок «ПАРАМЕТРЫ ЛАБИРИНТА»: девять чисел.**

| Параметр | Что это | Значение |
| --- | --- | --- |
| `ROWS` | строк в сетке | 3 |
| `COLS` | столбцов | 4 |
| `EXIT` | номер клетки-выхода | 12 |
| `START` | клетка старта | 1 |
| `GAMMA` | дисконт γ | 0,9 |
| `STEP_R` | награда за обычный шаг | −1 |
| `EXIT_R` | награда за вход в выход | +10 |
| `P_OK` | вероятность, что команда сработала | 0,8 |
| `P_SLIP` | вероятность сноса вбок | 0,1 |

Словами то же самое: сетка три на четыре, старт всегда S1, выход S12 в правом нижнем углу, команда
срабатывает в восьми случаях из десяти, по одному разу её сносит вбок, за границей сетки агент остаётся на
месте и всё равно платит за шаг, шаг стоит −1, вход в выход даёт +10, эпизод на этом кончается.
`CELLS` вписывать не нужно — он считается сам, как `ROWS × COLS`.

**Прогон — `run.py`, блок «ПАРАМЕТРЫ ПРОГОНА»: четыре числа.**

| Параметр | Что это | Значение |
| --- | --- | --- |
| `EPISODES` | сколько эпизодов в серии и в наборе опыта | 200 |
| `SEED` | зерно случайности: один seed — один и тот же эпизод | 7 |
| `EPSILON` | доля случайных проб, ε-жадная | 0,1 |
| `MAX_STEPS` | предел шагов на эпизод | 200 |

**Агент — `agent.py`: два места «на подумать».** Оба тела сейчас поднимают `NotImplementedError` — впишите
в них формулы:

* `q_value(state, action)` — **ценность шага по модели**: награда за шаг плюс γ, умноженная на среднюю
  ценность того, что будет потом. Строку переходов («куда и с какой вероятностью») отдаёт среда:
  `self.env.transitions(state, action)`.
* `learn(state, action, reward, next_state, done)` — **правило обновления из опыта**: оценка подтягивается
  к «награда плюс γ, умноженная на лучшую известную оценку следующей клетки». В конце эпизода (`done`)
  следующего шага нет — тогда берём просто награду. Результат запишите в `self.q[state][action]`, а пару
  отметьте в `self.seen`.

**Как проверять по шагам.** Каждый файл проверяет себя сам, поэтому можно идти по одному:

1. `python3 environment.py` — четыре проверки среды;
2. `python3 agent.py` — две проверки агента (сначала нужны вписанные числа среды);
3. `python3 run.py` — сводка по всей работе.

Пока что-то не вписано, файлы не падают, а говорят, чего не хватает.

**Признак готовности.** `python3 run.py` печатает восемь строк `[ok]` и «итог: все проверки сошлись».
Конкретно ждём:

* `среда: суммы вероятностей в каждой строке дают 1 (44 строки)`;
* `среда: за границей агент остаётся на месте (S1 → вверх → S1)`;
* `среда: доход маршрута из лекции = 4,58`;
* `среда: доход оптимального маршрута из S1 = 3,12`;
* `агент: строка q для S6: ↑1,97 · ↓4,13 · ←1,97 · →4,13`;
* `агент: строка q для S7: ↑3,77 · ↓5,93 · ←3,77 · →5,93`;
* `прогон: эпизод из S1 (seed = 7): S1 → S2 → S3 → S4 → S8 → S12 — 5 шагов, доход 3,12`;
* `прогон: таблица опыта 44 из 44, жадно из S1 — дошёл до выхода`.

**Где взять файлы.** [environment.py](/about/files/course/rl/environment.py) (среда),
[agent.py](/about/files/course/rl/agent.py) (агент) и [run.py](/about/files/course/rl/run.py) (прогон) —
скачиваем в одну папку и запускаем оттуда.

**Формат сдачи:** файлы присылают преподавателю лично (как и раньше по курсу).
